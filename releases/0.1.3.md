# cookietruck 0.1.3

## ct_authenticate

- Fix invalid enum handling in the authentication UI.
- Show the current URL in the window title.
- Add a **Copy URL** button.
- Add `--as-curl-cookiejar` to export cookies in curl cookie-jar format.
- Stop carrying cookies from one browser session to the next.
- Notify when copying to the clipboard.
- Add `--json-cookies-filepath` to seed the session with existing cookies from a prior JSON export.
- Add `--curl-cookies-filepath` to seed the session with existing cookies from a curl cookie-jar file.
